# 🃏 Card Designer

A free, offline, single-file business card designer that runs entirely in your browser.

**No accounts. No installs. No internet required after first load.**

## ✨ Features

- **Real-time preview** — See changes instantly as you type
- **Drag and drop** — Move any text element or QR code by dragging
- **Print-perfect** — What you see IS what prints (guaranteed 1:1 match)
- **Offline QR codes** — Generated locally, no API calls
- **Auto-save** — Your design persists when you close and reopen
- **Design history** — Clear archives your work; restore any previous version
- **One file** — The entire app is a single HTML file, under 50KB
- **Share with anyone** — Send the link or the file, they're designing in seconds

## 🚀 Use It Now

**[Open Card Designer →] [(https://dajaniart.github.io/html-business-card-generator-10-card-printout/)]**

Or download `index.html` and open it locally. Works without internet.

## 🖨️ Printing

Designed to print on pre-cut business card stock (10 cards per sheet: 2 columns × 5 rows).

### Print Settings

| Setting | Value |
|---------|-------|
| Margins | None |
| Scale | 100% |
| Background graphics | ON |
| Two-sided | ON (if printing backs) |
| Flip on | Long Edge |
| Paper type | Card Stock or Matte |
| Headers/Footers | OFF |

## 🎨 How to Use

1. Open the tool in your browser
2. Edit text fields on the left panel
3. Adjust colors with the pickers or hex codes
4. Resize fonts and borders with sliders
5. Drag elements on the preview to reposition
6. Click an element for Snap Back / Undo buttons
7. Toggle between Front and Back
8. Click **Print 10 Cards** when ready
9. Test on regular paper first!

## 💾 Your Data

Everything saves to your browser's localStorage. Nothing is uploaded anywhere. Your designs are private and local.

- **Save** — Manually saves current state
- **Clear** — Archives current design to history, resets to blank
- **Previous Designs** — View, restore, or delete archived designs
- **Load Template** — Loads an example design to see the tool in action
